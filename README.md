# gyosei-navi

人生イベントから、関連しそうな行政手続きを探しやすくするためのWebアプリ実験プロジェクトです。

引っ越し、結婚、出産、相続、退職など、生活の節目で「何を調べればよいのか分からない」という問題を、行政の公開データと自然言語検索を組み合わせて分かりやすくすることを目指します。

## 目標

- 一般の人が行政手続を探す入口を作る
- 専門用語を知らなくても、自然な日本語から関連手続を探せるようにする
- 可能な範囲でAPIキー不要・低コストで動作させる
- 将来的には静的サイトでも公開しやすい構成を検討する
- AIに計算や事実を丸投げせず、検索・抽出・集計は決定論的な処理を優先する

## 想定する使い方

例えば、次のような質問から関連する行政手続を探します。

- 「引っ越しするときに関係しそうな手続は？」
- 「結婚したときに調べるべき行政手続は？」
- 「出産に関係する手続を探したい」
- 「相続で関係しそうな手続は？」
- 「オンラインでできる手続はどれ？」

## 基本方針

このプロジェクトは、行政手続を法的・制度的に確定するサービスではありません。

AIや検索結果だけで「この手続が必須」と断定せず、利用者が公式情報を確認するための入口として設計します。

表示する情報には、可能な限り次の情報を添える方針です。

- データの出典
- データの基準日・調査時点
- 所管する行政機関
- 公式情報を確認するための手掛かり

## データについて

原則として、政府・自治体などが一般公開している公開データのみを利用します。

個人情報、勤務先の業務データ、社内情報、非公開資料などは使用しません。サンプルデータが必要な場合は、公開データまたは完全なダミーデータを使用します。

## 検討中の構成

初期段階では、デジタル庁が公開している行政手続関連データやMCPの設計を参考にしながら、次の2方向を検証します。

### 1. MCP版

```text
ユーザーの質問
      ↓
LLM
      ↓
MCP
      ↓
行政の公開データ
      ↓
検索・集計結果
```

### 2. ブラウザ完結版

```text
ユーザーの質問
      ↓
ブラウザ内AI または検索UI
      ↓
JavaScript / WASM
      ↓
公開行政データ
```

ブラウザ完結版では、GitHub Pagesなどの静的ホスティングで公開できる構成を目標の一つとします。

## 現在の状態

企画・技術検証を開始した段階です。

まずは以下を順番に確認します。

1. 公開されている行政手続データの内容を確認する
2. 公式MCPサンプルをローカルで動かす
3. 一般利用者に役立つ検索例を検証する
4. 静的サイト化できるデータ構成を検討する
5. 小さなプロトタイプを作成する
6. GitHub Pagesなどで公開できる形を検討する

## 注意事項

- 本プロジェクトは行政機関の公式サービスではありません。
- 制度や手続は変更される場合があります。
- 表示結果だけで重要な判断を行わず、必ず各行政機関の最新の公式情報を確認してください。
- 本プロジェクトの検索結果は、法律・税務・社会保険などに関する専門的助言を提供するものではありません。
